## 2024-07-04 - Fix NoSQL Injection in Forgot Password Controller
**Learning:** Even when inputs are checked against schemas like Zod or custom logic, failing to explicitly cast inputs or extract sanitized outputs (e.g. `req.body = schema.parse(req.body)`) leaves controllers vulnerable to NoSQL injection if they directly pass raw objects to Mongoose queries.
**Action:** When working with Express endpoints mapping request body properties directly into MongoDB queries, explicitly cast primitives (`String(req.body.email)`) or ensure a sanitization middleware strictly enforces scalar types for query selectors.
